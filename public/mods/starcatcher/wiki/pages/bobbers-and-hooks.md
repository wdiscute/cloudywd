# Bobbers & Hooks

Hooks and bobbers are the main way to add **modifiers** to your rod. Each one gives a different modifier that helps you in its own way.

Picking the right hook and bobber is a big part of Starcatcher's strategy. You can swap them at any time using a [Tackle Box](tackle-boxes).

Learn more about casting and the minigame in [Fishing Basics](fishing-basics).

## Hooks

{{items #starcatcher:hooks}}

| Hook | Effect |
|---|---|
| {{item hook}} | The basic hook. No special effects. |
| {{item stone_hook}} | Fish take longer to bite, but they can't swim away for a moment after each sweet-spot you hit. |
| {{item copper_hook}} | Greatly speeds up the handle. |
| {{item exposed_copper_hook}} | Speeds up the handle. |
| {{item weathered_copper_hook}} | Slows down the handle. |
| {{item oxidised_copper_hook}} | Greatly slows down the handle. |
| {{item heavy_hook}} | Moving sweet-spots move slower. |
| {{item mossy_hook}} | A perfect catch has a chance to give you treasure. |
| {{item frozen_hook}} | Stops your handle from freezing up. |
| {{item rusty_hook}} | Fish are easier to reel in, but it increases the penalty for missing a sweet-spot. |
| {{item shiny_hook}} | You can't see your catch while fishing, but hitting 3 sweet-spots in a row brings up a treasure chest. |
| {{item split_hook}} | An extra fish comes up with your catch. |
| {{item gold_hook}} | A golden fish is more likely to bite. |
| {{item amethyst_hook}} | Lets you fish in lava. |
| {{item echoing_hook}} | Fish you haven't caught yet are more likely to bite, but hitting sweet-spots slowly covers the screen in darkness. |
| {{item vanilla_hook}} | Paired with the {{item vanilla_bobber}}, skips the minigame entirely. |

## Bobbers

{{items #starcatcher:bobbers}}

| Bobber | Effect |
|---|---|
| {{item bobber}} | The basic bobber. No special effects. |
| {{item steady_bobber}} | Green sweet-spots are slightly bigger. |
| {{item clear_bobber}} | Vanishing sweet-spots take much longer to vanish. |
| {{item slimey_bobber}} | Once per catch, bounces a fish back up instead of letting it swim away. |
| {{item leaf_bobber}} | Leaf sweet-spots appear at random. |
| {{item dripstone_bobber}} | Adds a Dripstone sweet-spot. |
| {{item glowing_bobber}} | Adds a Glowing sweet-spot. |
| {{item golden_bobber}} | A golden fish is more likely to bite. |
| {{item cloud_bobber}} | Your bobber no longer follows the laws of gravity. |
| {{item vanilla_bobber}} | Restores vanilla fishing loot. Paired with the {{item vanilla_hook}}, skips the minigame entirely. |
